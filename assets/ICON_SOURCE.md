# Icon source

Icons are downloaded from the dashboard-icons collection (repository `homarr-labs/dashboard-icons`)
and the selfh.st icon collection (repository `selfhst/icons`), both served via jsdelivr.
No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `homarr-labs/dashboard-icons/svg/actual-budget.svg` | Default (full-color logo) |
| `icon-dark.svg` | `selfhst/icons/svg/actual-budget-light.svg` | Light-colored logo for dark mode |
| `icon-light.svg` | `selfhst/icons/svg/actual-budget-dark.svg` | Dark-colored logo for light backgrounds |

Download URLs:

- https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/actual-budget.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/actual-budget-light.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/actual-budget-dark.svg
